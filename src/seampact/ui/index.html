调度模式与联合配置

联合模式按工作负载窗口运行，episodes 为窗口数；需填写 age_guard_ms、max_consecutive_resource_ops、workload（tasks_per_window、arrival）、costs（task_seconds、instance_seconds）与 scales；扩缩容实验须至少两个根调用槽（capacity.call_slots ≥ 2）。派发默认 fifo/1、资源默认 fixed/1；联合学习须显式设置 dispatch_policy: learned_ready/1 与 resource_policy: learned/1，并使用到达相互重叠的任务。功能模式下留空。
