本地模型、API 和权重分别在哪里配置？
  • 本地或云端模型已提供 OpenAI 兼容 API：在此选择“OpenAI 兼容接口”，再到“模型角色”应用到对话、分析或教师。分析模型还需支持工具调用。
  • Harness 使用自有 HTTP 接口：选择“原库专用 HTTP 接口”，保留原客户端及原参数；不能直接作为平台对话或分析模型。
  • 只有模型权重文件，还没有启动服务：去权重资源登记本机目录或文件。原 Harness 按自己的加载器使用这些文件；平台不会仅凭登记路径启动推理服务。
  • “API”是调用方式；本地与云端是部署位置。这里选择的是接口格式，HTTP 和 HTTPS 地址均可使用。仓库源码则在Harness 接入登记。

新增命名连接

编辑会更新原连接。要保留旧模型并登记另一个模型，请先点击“新建”。

云端和借用连接需已有可用服务；平台管理服务可先登记规格，再由调度器准备。如果只有权重文件，请先登记权重路径。

服务声明能力（实际操作另行核对）

按提供方官方文档填写生成参数，例如 {"reasoning_effort":"max","thinking":{"type":"enabled"}}。文本、图像能力调用及平台对话／分析／教师请求会携带这些参数；保留 model、messages、tools 等平台请求字段，不在这里填写。向量接口只使用其支持的参数；Harness 原库按已核对的映射读取参数。

凭据值使用下方独立表单保存。更换地址后需重新明确认证方式。

连接私有凭据

Windows 使用当前用户 DPAPI；Linux 使用服务器私有目录及文件权限。环境变量引用只保存变量名。迁移机器需重新配置凭据。

明确调用连接能力

使用下方明确输入向已启动服务发起一次真实能力调用，可能产生费用。此结果只核对连接操作；Harness 原目标执行仍单独记录。保存、检查连接及页面刷新都不会触发此调用。

首版支持已声明 text、image 或 embedding 能力的 OpenAI 兼容连接；其他协议使用原库客户端。

权重资源

路径属于平台实际执行环境：Windows 填 Windows 路径，Linux 填 Linux 路径，Docker 填容器内路径。权重放在独立目录，例如平台 models 目录；不要登记平台克隆的来源目录，来源删除时该目录会一起清掉。登记远端机器的目录不会把文件同步到此处；原库直接加载模型对象时仍须由原宿主读取。

  1. 先把原 Harness 所需的模型文件准备在平台可见的位置。此页登记已有路径，不下载权重。
  2. 在下方填写名称、选择“目录”或“单个文件”，再填写完整路径。多文件模型通常登记整个目录；格式以原加载器要求为准。
  3. 目录的必要文件每行填写一个相对文件名；保存后点击该资源卡片的“检查资源”。文件存在不等于模型已加载或调用成功。
  4. 返回来源与能力继续准备；平台自动匹配资源。若仍有缺口，可在能力包中补充已登记权重。
