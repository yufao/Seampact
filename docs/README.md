## 记录与术语

[历史索引](history/README.md)集中保存实际运行与接入证据。[版本更新](版本更新/)按版本记录功能变化；[来源专项](来源专项/)说明特定库的资源和原宿主，不定义整个平台的要求。

生成、镜像准备和能力首调具有不同状态；接口或构建通过不等于任务效果及调度收益已验证。能力重构按实际接口和任务行为评价；只有明确验证过的转换才声明相应语义保持。

研究结果保存冻结源码、配置、环境、策略和工作负载。声明资源乘驻留时间是预留成本，进程／容器实际采样是归属测量，整卡采样是设备观测；三者不能混称，也不能据外部服务连接估算其内部显存为零。
