## 术语和证据状态

- **来源**按独立项目去重；完整防护流程、防护组件、检索补证、任务宿主及评价设施分别计数。同库尺寸/版本不增加来源数。
- **分析完成**表示已有冻结源码及候选检查报告；缺资源可以静态分析完毕。分类的功能标签只是调查假设，不签发拆分/远程/并行权限。
- **READY / STATIC_READY** 是静态条件状态；文件检查的 present 只覆盖声明文件，均不等于真实模型初始化或原目标成功。
- **原生运行成功**要求真实输入与实际输出；**可评价**还要真实标签/参考/掩码和实际评分。直接原生脚本不计为平台自动接入。
- **平台成功**需经原仓库→分析/检查/构建→Unit→原目标执行，并记录自动或人工修订归因。正式效果保持与资源收益需再做配对。
- **functional/1** 的下层用 FIFO；**joint/1** 可学习合法就绪根请求及内部检查边界派发、已获准的生命周期动作，全部受原依赖、owner、效果与原子准入约束。
- 实例时间/逻辑配额、实测显存时间积分、设备能耗估计、实际账单是不同量。缺数据用未知，所有到达任务保留分母。
