# 策略版本与分支训练

调度器页的“策略版本”管理能力调度网络，业务模型仍由模型配置单独选择。普通交互使用选定策略进行推理；点击导入、保存或查看结果不会启动训练。

## 使用顺序

1. 点击“发现并导入已完成实验”，登记可验证的冻结训练方案及对应检查点，并复用相邻已记录的独立评分配置。也可在高级导入中填写平台数据目录内的冻结协议路径。包含表格训练题且未找到已有评分配置时，需要登记独立原生评分器的参数数组，其中一个完整参数为 `{collection}`。
2. 在版本卡片中查看来源、父版本、训练量和五维结果。“训练”与“冻结开发评价”的指标分别标注，不把训练分数当验证结果。
3. 点击“用于后续任务”。只有当前任务、调用、实例和训练工作负载已收尾时才能切换；错误会保留当前选择。普通聊天随后走这一冻结策略，不会隐式更新网络。
4. 在对话或任务详情打开“任务运行记录”，查看实际策略版本、决策步骤、能力调用、防护处置和资源实例。活动任务自动刷新，关闭后停止读取。
5. 手动开始训练时选择已登记方案，指定新训练、原样续训或改参分支。每次真实更新都会保存可选择的检查点。暂停在完整派发段收尾、计量和原生评分结算后生效；恢复暂停任务沿用同一协议与剩余题序。

## 三种训练操作

| 操作 | 继承内容 | 参数变更 |
|---|---|---|
| 新训练 | 按方案初始化网络、优化器和随机状态 | 可显式设置学习参数、偏好、平滑度、种子与更新间隔 |
| 原样续训 | 决策及价值网络、优化器、计数、随机状态、已生效系数 | 保持目标、调度语义和学习配置一致；新任务序列仍需由冻结训练方案提供 |
| 改参创建分支 | 继承父决策网络；分项回报语义不变时同时继承价值网络 | 新优化器、计数、随机流与结算历史；改变奖励尺度或定义时重新初始化相应价值估计 |

“恢复暂停任务”与“从已完成版本原样续训”不同：前者恢复原任务剩余序列，后者创建有独立身份的新训练任务。新任务不会覆盖父检查点。修改偏好和平滑度不改变五个分项回报的含义，可以继承五个价值网络；动态系数在分支开始时按新偏好初始化。归一化尺度来自原训练侧校准，不在训练表单中任意改写；新尺度应通过新的已校准方案导入。

## 工件与任务归属

- 策略权重按内容摘要存于平台数据目录的 `policy-versions/weights/`，版本记录保存在同一平台数据库。登记时验证检查点目标、特征、结构与文件摘要；选择或继承时再次核验。缺失或变化的文件明确报错，不静默退回规则。
- 冻结方案保存在 `policy-versions/recipes/`；后台训练状态与逐题证据在 `policy-training/<任务标识>/`。平台重启后，不把尚未结算的轨迹宣称为可恢复；已保存版本仍可创建新分支。
- 任务到达时保存策略版本、配置身份及策略更新版本，后续切换不会改写旧任务归属。正在训练的任务还关联训练任务标识与对应中间检查点。
- 历史记录中的“来源训练任务”仅表示工件来源，不表示所有训练题都使用最终权重执行。只有匹配相同检查点配置的冻结开发运行才作为该版本开发指标。
- 五维指标包括原生业务质量、真实时延、受管能力实例 RAM/VRAM 积分及真实 token。未知不填零。共享实例生命周期资源与单任务质量、时间、token 分开显示，避免把共享资源完整重复归给每道题。

## 运行边界

同一执行器同时运行一个训练工作负载。训练完成、安全暂停或启动失败后，尽可能恢复训练前的冻结推理选择；有真实活动任务或未释放资源时保留现场并显示收尾错误，不强制重置。训练期间只接入方案训练划分，原生评分仍经原隔离评分链完成，正式留出不由本入口自动运行。

失败训练仍有任务或实例未释放时，等待这些工作结束，再点击“重新收尾”。该操作只核对本训练拥有的真实任务前缀并释放，不补派题、不更新权重，也不会把失败状态改成成功；归属不匹配的其他工作负载会被拒绝。

切回策略只改变后续调度行为，不撤销已产生的文件或业务副作用，也不恢复业务模型缓存或实例冷暖状态。对比试验应另行固定输入及运行起点。当前不支持在一个未结算的 PPO 块或正在执行的任务中任意热切换。
