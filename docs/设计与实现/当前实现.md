# 当前实现与边界

更新：2026-11-11，源码版本 0.16.0。目标见[平台设计](Harness接入与调度重设计讨论.md)，后续工作见[实现计划](实现与落地计划.md)。本页描述已经接通的主路径，不把接口检查或示例调用当作实验结论。

## 执行主线

完整仓库 → 读取代码、配置和说明 → 生成能力包 → 准备独立运行环境 → Agent 按需调用 → 流式正文或文件交付。

总入口已改用新能力包，不再自动恢复旧分析、安装旧 Unit 或启动旧训练器。旧记录可查看和导出；旧检查点不会自动载入新策略。实例身份、调用排空及后端释放机制继续复用。

## 仓库接入

生成器冻结仓库，按需读取源码、依赖和示例，产出能力描述、标准适配与复用源码。平台检查接口、内容身份、生成代码语法和引用；可修复错误在同一任务内有限处理。默认保留完整用途，多个方法可以共用一个实例，不因函数数量而拆容器。

首版面向 Python 仓库和明确环境声明。生成提示偏向先提交一个完整用途；当前只接受 adapter/ 下的生成 Python 文件，来源文本整体复制，尚未支持目标设计中的生产文件选择、一般源码重构和多 Unit 部署。二进制资产与通用输入文件流程仍待补齐。源码引用及样例运行不构成任意代码等价证明，也不承诺覆盖一个库的全部功能。

平台从已登记资源中自动匹配无歧义的连接、权重和确定默认值。Docker 权重可自动形成只读挂载；平台在容器中时，宿主路径仍需能由已有映射确定。缺失文件、资源冲突或不能确定的条件显示为具体缺口。

能力包自动安装、准备镜像，并对具有源码依据且效果允许的样例首调。未通过首调的生成能力不进入 Agent 工具列表；明确人工调用成功也可开放相应能力。镜像构建和业务首调分别记录。

## 通用 Agent

正常流程为输入、模型流、完整工具参数、能力调用、工具结果回传及交付。当前是自有 AgentRuntime，尚未替换为开源精简宿主；它可供在线对话和后续负载驱动使用，新的基准环境适配尚未完成。业务模型提出工具需求与参数，调度器决定合法请求的执行时机和实例生命周期。

插件接口覆盖输入、工具前后和交付前。必需插件不被可选选择器跳过；全文检查先缓冲正文，分片检查在交付前处理。目前通过 Python 回调注入，主服务默认没有防护 hooks，也没有完整应用绑定入口；工具前阻断和交付前替换已有路径，输入／工具结果的替换尚未完整支持。已经交付的内容不能追溯撤回。

取消停止继续交付，并请求取消在途操作。工具在安全点退出才记为确认取消；关闭 HTTP 流不证明远端模型停止计算或计费。流中断不重放可能已经执行的调用。

会话继续使用服务端记忆；活动流只留有限事件队列，终态写入记录，历史分页读取。文件以内容身份提供下载。

## 调度与目标

已实现的实际动作是就绪调用派发和空闲实例释放。容器按需启动，温实例复用，空闲超时后排空并确认释放。规则默认按期限和 FIFO 派发；只有一个合法动作时直接执行，不制造学习样本。空闲阈值是可配置运行设置，不是本轮实验参数。

PPO 使用同一候选接口，保留候选评分和裁剪更新。目标、特征和执行语义参与检查点身份，旧预算轮换检查点拒绝加载。新平台默认规则，尚未训练新策略。可选插件选择接口存在，但尚未定义具体应用的学习任务。

统一配置同时容纳质量、交付、时延和 RAM／VRAM 成本；系数与尺度留待实验设计确定。没有目标配置时只记录分项。质量未评分或所选成本口径缺失时，效用保持未知，不偷偷填零训练。失败和未交付保留在全部到达分母中。

实测与预留分开。实测只使用可核对实例归属的容器内存与 GPU 进程数据，不把整机 RAM、整卡显存或其他程序直接计入能力成本。共享实例计一次，启动、空闲及释放尾段均在成本范围内。采样缺口保留覆盖率，不能当作完整积分。外部模型费用不由本机内存推算。

新资源账本在线累计活动实例，确认释放后冻结汇总并退出活动索引；历史按需读取。旧部署控制器仍有历史对象整理工作，不能据此宣称全仓所有路径已经有界。实测首尾采样缺口目前可能令完整成本保持未知，观测边界和训练结算还需改进。

## 已验证与后续范围

契约、HTTP worker、流式工具循环、必需插件、取消、历史分页、实际队列和 PPO 检查点已有针对性检查。完整 Mistune 仓库已由真实模型生成能力包，通过 Docker 首调和释放；普通聊天也已真实调用该能力、返回正确 HTML，并由空闲规则确认容器释放。细节和首轮失败见[运行记录](../history/实现与运行记录.md)。文件交付与受管模型租约有接口检查，本轮真实链路使用文本工具和外部模型连接，尚未实跑新的 GPU 模型能力。

2026-11-11 只读核对的新平台能力池只有一个 Mistune Markdown 渲染来源和能力，没有已接入的安全防护池。在线任务结束时质量仍为空，PPO 更新函数尚无生产训练驱动调用。数据集、原评分、混合负载、统一系数和正式比较已进入文档设计，尚未运行或训练，见[数据源选型](../研究实验/Agent任务与攻击数据源选型.md)。

用户手动提交本轮设计后再推进实现与实验。11 月 10 日五来源数据仍按原版本解释：12 个训练窗与两种资源偏好等原始记录保留。旧图的 RL 汇总来自两次评估的各项较优值，不是一套配置同时得到的联合结果。
