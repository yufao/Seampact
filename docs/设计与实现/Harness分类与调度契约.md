# 能力与执行契约

更新：2026-11-11。本文规定目标契约；当前 capability-package/1 的实现子集见[当前实现](当前实现.md)。契约由平台根据仓库生成，人工入口用于真正的缺口和覆盖。

## 四个运行对象

| 对象 | 定义 |
|---|---|
| 能力操作 | 可重复调用的完整用途，具有输入、输出、失败语义 |
| 部署单元 Unit | 共同持有资源和状态、一起启动与关闭的一组实现 |
| 实例 | Unit 的一个运行进程或容器，具有独立身份和容量 |
| 调用 | 一次操作执行，绑定请求、输入、实例、结果和取消状态 |

能力包是发布单位，可以描述多个操作和 Unit。仓库、包、操作、Unit、实例之间不能默认一一对应。无独立资源边界的普通函数不成为部署单元。多个方法共享模型和活对象时保留同一所有者。

## 最小描述

| 内容 | 必须明确的语义 |
|---|---|
| 调用接口 | 输入输出类型、文件引用、实际执行方法、失败与取消 |
| 应用挂载 | 适用事件、输入来源、平台触发／模型申请、模型可见性 |
| 应用约束 | 必需或可选，允许继续／替换／阻止／结束哪些操作 |
| 所有权 | 调用临时状态、实例可重建缓存、会话业务状态及其删除者 |
| 资源与效果 | 权重、服务、资产、设备、文件与外部写入；拥有或借用 |
| 生命周期 | 初始化、一次或重复调用、排空关闭、并发限额、复制条件 |
| 来源 | 所选文件、依赖、资产、改写关系、版本与构建身份 |

以上是同一能力描述和应用绑定的字段，不要求用户维护多套表。应用是否要求某项检查，由应用政策决定，不能仅从来源库说明推导。平台可从已知配置生成默认绑定，仅在意义不明或条件冲突时询问。

## 执行与挂载

执行端保留 initialize(bindings)、操作方法(input, context)、close() 三类接口。context 提供调用身份、输入资产、输出位置、事件和取消；业务数据使用值或制品引用交接，不传递模型对象或活进程句柄。

操作可供多个挂载位置使用。检查挂载将原方法结果解释为受限的干预决定；不强迫所有原算法改写为分类器。查询和计算返回业务结果，监控只观察，修改和阻断由宿主实际执行。

工具调用参数完整后再执行。外部材料进入模型、外部效果发生、内容交付前分别有相应控制位置。多个插件消费原值或替换后值的顺序明确；必需检查失败不能伪装成通过。输出的阻断不能撤销已发生的写入；取消不是事务回滚。

## 状态、复用与取消

调用状态仅属于一次执行，终态后按引用清理。实例缓存只保存可重建内容；跨调用业务状态必须声明会话／业务所有者和结束条件。能够明确持久化的状态由宿主或专用存储保存，不能强迫任意活状态自动序列化。

共享实例按 Unit 版本、资源配置和隔离范围匹配。只读模型允许按实现能力复用，缓存必须隔离必要的用户和凭据范围。每实例并发上限和全局容量是两个量。复制须符合状态与效果语义；未知线程安全时串行，不凭 replicable 标签自动保证正确。

取消按调用身份请求，执行登记与取消之间不能漏掉请求；记录请求取消与确认取消。仍有在途调用或会话占用的实例不能回收。借用外部服务只关闭本方连接，不获得服务进程的关闭权。多客户本轮只设计接口。

## 文件和资源

输入文件以只读资产引用映射到实例，输出写入调用专用位置，交付确认后移出临时生命周期。来源内模板、词典等运行资产纳入生产闭包；权重及大型共享资产独立登记引用，凭据不写入包。

数据资产进一步区分版本化语料／索引、任务或会话工作区、单次临时文件与交付件。描述记录资产ID／版本、归属、读写范围和保留条件，平台自动映射路径；工作区的有效期可以跨调用但不能被空闲实例回收顺带删除。此为目标契约，当前资源枚举尚未包含通用数据卷。详见[工作区与知识资料](上下文记忆与来源更新.md)。

声明的外部效果与运行许可分开。模型声称“无副作用”不能代替实际权限约束，也不能据此宣称任意来源代码安全。生成代码在 worker 执行，平台进程不导入生成实现。

## 重构与独立部署

默认保留完整用途，允许一个库产生多个真正独立的 Unit。提出拆分时同时说明明确输入、状态／资源所有权和新增可用调度动作；没有这些依据则保留内部调用。合并与拆分的比较双方都允许正常加载、缓存和释放。

生产代码可以按能力范围重构；来源原件不变，产物记录改写。接口检查、成功调用、任务效果和特定语义保持是不同结论。只在特定转换需要时做限定语义验证，不把通用全库证明变成接入前提。
