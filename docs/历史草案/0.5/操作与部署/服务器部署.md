# 服务器运行与数据边界

代码从 GitHub clone／pull，优先使用[单服务 Docker 部署](Docker部署.md)。服务器操作由用户在 SSH 终端执行，不重复已知硬件盘点。

不使用 Docker 时，在项目专用 Python 环境安装 `docs/requirements-sdk-crag.txt` 和当前包，然后运行：

```bash
python -B -m seampact serve --home var/platform --sources sources.json --port 8874
```

Linux只从进程环境或项目私有秘密目录加载 Key，不在网页中明文落盘。可在启动前隐藏输入：

```bash
read -rsp 'DeepSeek API Key: ' DEEPSEEK_API_KEY
printf '\n'
export DEEPSEEK_API_KEY
python -B -m seampact serve --home var/platform --sources sources.json --port 8874
```

终端只输入一次Key，不写进命令文本。浏览器通过SSH回环端口转发，登录令牌随启动更新。前台进程由Ctrl+C关闭；有活动API请求时，其付费结果可能未知，不自动重发。

Git保存：源码、配置模板、固定来源坐标、当前设计。SFTP按需传：模型、数据集、已有能力包与运行记录；真正的Key仅在服务器私有配置中填写。`var/`、`artifacts/`、`sources/`、秘密目录和大型二进制均被Git忽略。
