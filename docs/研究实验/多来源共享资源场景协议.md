# 混合 Agent 工作负载与运行协议

更新：2026-11-11。本文是新实验目标协议，尚未冻结数据清单和执行参数。业务运行使用同一精简宿主、模型、能力接口和调度路径。历史五来源流程及结果见[运行记录](../history/实现与运行记录.md)，不恢复为新平台默认任务。

## 三个候选场景

| 场景 | 正常任务来源与业务 | 风险来源及所需能力 |
|---|---|---|
| 办公协作 | AgentDojo 的协作任务；SpreadsheetBench 工作簿编辑；后续加入有独立判分的资料／文档任务 | AgentDojo 工具材料注入；AgentDAM隐私任务适配；输入与外来材料、操作目标、敏感信息和交付检查 |
| 软件工作台 | AgentDyn GitHub类任务；SWE-bench修复；有可检查结果的代码查找、说明修改和诊断任务 | AgentDyn原生攻击；安全适配后的仓库／命令输出污染；工具操作、密钥泄露和补丁检查 |
| 资料与文档 | AgentDyn检索类任务；AssistantBench；有授权的GAIA附件任务；需要时补独立文档数据 | AgentDyn原生攻击、AgentDojo外来材料；InjecAgent／BIPIA仅作为明确改造的局部素材；来源、隐私、事实和交付检查 |

这是选型组合，不表示已适配。数据集具体任务套件与版本以[来源表](Agent任务与攻击数据源选型.md)及运行清单为准。不同环境可共用宿主但保留原工具和状态；不能将多个不兼容世界拼成一条伪造轨迹。混合发生在任务到达序列层，同一任务仍保有自己的完整环境和判分。

## 任务表示

每个任务包含来源／版本／原ID、初始环境、用户输入与附件、可用业务工具、应用要求、终态与评分适配。业务工具用于完成任务，防护库用于所声明的保护，原评分器用于观察结果；三者分别登记，不以benchmark框架数量充当防护库数量。

任务交付可以是回答、文件、代码补丁或环境状态。保留需要多轮工具、直接回答、正常外部指令以及不同异常的任务。每场计划七至十个来源库；同源框架内多个scanner／模型不重复算多个来源库。每个库有实际适用任务与可观察调用，不强制所有任务都调满能力池。

## 混合与划分

正常请求为多数。具体比例、风险类别占比、任务数与长度分布在准备开发负载后固定，不声称存在自然用户流量。攻击型基准的benign变体只作为对照，不单独代表日常使用。正常请求也可以需要检索、核验和工具，风险任务可能在执行前被阻断。

固定基础任务及其变体的分区，避免同一仓库、文档或攻击模板泄漏到训练与冻结评价。先记录每个来源原生划分；不能因为公开有答案就把官方测试拿去训练。跨场景复用任务或Dojo/Dyn继承套件须去重。缺少可用训练划分的来源只作评价，训练另取合适数据。

本轮先单会话／顺序请求，共享实例可以跨请求保留；使用共同预定输入清单和间隔规则，按方法真实完成时长运行，不截掉慢方法的任务。固定墙钟到达、排队与多客户并发属于后续单独条件；不从本轮推断吞吐或多租户收益。

## 原生评价

保留正常任务utility、受攻击任务utility与攻击成功率各自分母；攻击未成功不等于用户任务成功。程序错误、取消、超时和未交付均保留。原评分器能从终态确定成功则照常判；无法评分则记录未知和覆盖，不能将解析故障改成攻击失败或安全成功。

正常任务上的拒绝／阻断事件单独统计，不把所有失败算作误拒。泄露、越权执行和内容有害分别按原指标解释；仅检测目标工具名的指标不能称实际泄露完成率。模型裁判版本、提示和失败处理冻结，调度器不可访问标签或裁判答案。

复用原环境／工具／评分并替换被测Agent是正常接入；改变任务、工具语义、攻击入口或判分时记录具体改造。混合子集报告为本研究负载及分来源指标，不冒称官方完整榜单分数。

## 训练与策略

统一目标配置容纳任务／防护效果、交付、时延、RAM、VRAM和适用费用，系数及归一化尺度由开发侧确定。终态原评分转换为训练奖励；各项指标仍独立保存。有限完整负载的事件回报须与总体结算对应，资源不重复扣除；观察缺失不补零。

应用必需步骤、状态所有权、容量和在途约束由执行器保证。候选包括实际适用的可选防护、合法执行及真实可控的实例动作。内容信号来自当时输入与返回材料，资源特征来自归属实例；只有一个合法动作时直接执行。

训练完成后冻结检查点和目标，不在线更新评价组。常规配置、调优规则、PPO使用相同数据、环境、宿主、工具／防护和计量范围。运行顺序平衡，重复数由预算确定；小批次如实报告样本量和不确定性。

## 成本、留存与结果

从请求开始记录模型、工具、防护、等待与交付时间；实例启动、忙碌、空闲和释放尾段均纳入所属运行。业务模型、基础环境、防护实例、调度开销分别计量，同时给出可覆盖的总成本。外部API无法本地测内部内存，报告调用／token／费用等可核对量。

来源包和权重按身份引用，调用临时物终态后回收，交付件独立保存。实验记录含任务原ID、配置／代码／能力身份、调用与实例事件、原输出、原评分和有效测量；运行时仅加载当前状态，不扫描全部历史。

冻结比较至少输出分来源任务与攻击指标、拒绝与失败、时延分布、归属RAM／VRAM积分、调用与冷启动／释放次数、覆盖率。总体混合结果按预定权重计算，同时保留各来源原始指标，不能只给奖励总分。
