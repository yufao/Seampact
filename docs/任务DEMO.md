# CRAG任务DEMO

页面提供完整操作链：来源快照、API分析、能力包、问题／文本资料、运行与回答。任务宿主采用真实LlamaIndex Workflow SDK，执行包内冻结的原方法，生成adapter控制原生调用的实际开始。

启动、接口设置、可直接复制的问题／资料和演示次序见[手动启动与演示](手动启动与演示.md)；当前研究与实现范围见[组会报告](组会报告.md)。

## 两类包

- 当前分析生成的包：来自当前冻结请求和完成的API候选，运行前重新检查包、候选和来源版本。
- 已有API能力包：显式通过`--artifacts`加载原ZIP与`crag-text.json`，摘要和记录匹配后才运行。

宿主只接收支持的CRAG修订和W／H调用边界、评价循环R提取；不支持的方案返回具体错误，不自动改包或换成示例。

## 两种执行模式

真实模型使用配置的DeepSeek／GLM完成相关性评价、必要的查询改写及最终回答；检索与搜索仅使用用户提供的资料。模型调用失败保存当前结果状态，不自动重放。模型用量未知时保持未知。

受控预览使用明确标记的固定端点，不发付费请求。它帮助展示调用流程，不替代真实回答。

调度器释放原SDK已启用的能力调用，按FIFO执行；当前不改写原控制流的分支决定。结果显示已激活模块、调用次数、SDK无效果分支、账本和模型用量。运行成功表示这个任务完成，不授予并行或生产准入。
