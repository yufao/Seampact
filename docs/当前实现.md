# 当前实现与代码对应

更新：2026-10-13，0.6.0。本文记录正在实现的四层原型；旧 0.5 的 CRAG 专用任务链不作为当前平台入口。

## 从地址到能力池

1. 前端提交仓库 URL 或本地目录，可附修订、入口说明和资源路径。
2. `RepositoryIntake` 取得实际目录，递归登记源码／配置／文本与二进制资源引用。远程仓库在私有工作目录中克隆并记录实际提交；本地目录保持原位置。
3. `Inspector` 冻结分析文本，提供整仓结构、入口候选、AST 符号、导入和源码读取。Notebook 输出不发给模型；代码单元按实际索引定位。
4. 分析 API 在平台的工具循环中自行找入口和边界，提交 `entries` 与 `boundaries`，没有来源专用的预填切点。
5. `check_candidate` 同时返回边界与原生入口检查，API 可根据真实参数接口和缺失原因修正候选。引擎按已确认 RuleSet 检查源码锚点、签名、初始化、资源和有限 W／H／R 接线。`UnitCatalog` 保存入口、参数接口、状态及缺失原因。

当前原生执行支持有限 Python 函数／实例方法和原仓库 CLI。其他语言可以出现在来源结构和文本分析中，但不能因此声称已经拥有相应语言的原生执行后端。

## 从对话到原生执行

对话模型看到的是能力池中实际可调用的 Unit 及参数接口。需要使用能力时，它通过 `execute_harness_plan` 提交相同任务要求下的候选完整方案。上层调度器在符合当前调用条件的候选中选择一个；方案步骤顺序执行。

进入 Unit 后，原 Harness 的对象、初始化和 controller 保留。内部 W／H／R 边界在原控制流到达时才使能。下层调度器从 owner 和资源条件允许的已使能调用中选择；包装入口等待许可后进入原 callable。返回值或异常交回原继续路径，再送回对话模型完成回答。

当前没有通用的跨步骤变量引用语言。需要前一步真实结果才能绑定的后一步，在下一轮模型工具调用中生成参数；不会提前编造未来结果。

## 状态的准确含义

| 状态／概念 | 当前含义 |
|---|---|
| 分析完成 | API 已提交结构化候选且引擎已形成接入结果，不表示原代码已运行 |
| `READY` Unit | 受支持范围内静态绑定准备完成；原生初始化尚未运行 |
| `MISSING` Unit | 缺依赖、参数、资源或原生接线支持，保留原因，不暴露为可调用工具 |
| 激活调用 | 当前真实任务到达的原生边界，不是分析结果中的所有边界 |
| 上层候选合法 | 引用已绑定 Unit，并符合当前参数与要求格式；模型列出的要求仍不是完整语义证明 |
| Q 更新 | 实际调用或方案结束后，根据成功／失败与时延更新表格；不等于效果优于其他调度器 |

## 代码位置

| 代码 | 核心职责 |
|---|---|
| [`ui/`](../src/seampact/ui/) | 普通对话、配置、运行观察 |
| [`intake.py`](../src/seampact/intake.py)、[`inspection.py`](../src/seampact/inspection.py) | 真实来源接入、整仓清单、冻结和源码工具 |
| [`analysis.py`](../src/seampact/analysis.py) | 确认规则下的 API 工具分析循环 |
| [`verification.py`](../src/seampact/verification.py)、[`lowering.py`](../src/seampact/lowering.py)、[`handoff.py`](../src/seampact/handoff.py) | 源码结构检查、有限循环提取与原生接线 |
| [`units.py`](../src/seampact/units.py) | 原生入口绑定、owner 初始化、能力池 |
| [`runtime.py`](../src/seampact/runtime.py) | 原调用使能、许可、owner 占用、返回与退休 |
| [`scheduler.py`](../src/seampact/scheduler.py) | 两层在线表格 Q-learning |
| [`chat.py`](../src/seampact/chat.py) | 完整对话、候选方案、实际 Unit 调用与结果回传 |
| [`providers.py`](../src/seampact/providers.py) | 独立模型角色、OpenAI 兼容 API |
| [`service.py`](../src/seampact/service.py)、[`server.py`](../src/seampact/server.py) | 四层连接与页面状态接口 |

平台核心不安装第三方 Harness 的运行依赖。依赖必须存在于实际 Python 环境；未知 SDK wiring、需要真实 Model／Context 对象的输入、继承构造器等未覆盖条件显示为缺失。当前未开放并行和远程派发。
