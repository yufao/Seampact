# 查看分析结果与补齐接入条件

“分析完成”表示这一轮分析结束。入口静态可绑定、资源可用、真实调用成功和任务效果分别记录。

## 预处理结果是什么

预处理先阅读冻结源码，查找实际功能、原入口、构造与初始化方式，以及服务和权重需求。保存的“预处理工件”是交给后续拆分分析的中间记录，包含源码位置、入口候选、依赖和未解决条件。

预处理不运行原功能，不安装 Unit，也不决定 W/H/R 边界或运行组。后续拆分分析仍可调整入口，并接受独立检查。

“来源与分析”先显示目标、功能位置数、候选入口数和外部依赖数；展开可看用途与源码位置。原始 JSON 和内部编号放在“预处理技术记录”。预处理时的缺口属于历史发现，当前状态以最新分析结论、依赖配置和能力池为准。

## 条件补齐后怎样接入

| 缺少什么 | 怎样补齐 | 后续操作 |
| --- | --- | --- |
| 服务或权重，原参数映射已核对 | 在配置中登记服务或权重并检查，在来源的“依赖配置”选择资源 | 点击“保存选择并重新接入”，使用已有候选核对并接入满足条件的入口，不再调用模型 |
| 原库要求的固定文件 | 按页面显示的原位置准备文件，并检查位置 | 点击“重新检查并接入可用入口” |
| Python、包或宿主环境 | 在 Harness 配置中准备和核对运行环境 | 从最新分析记录重新检查并接入；环境变化可能使旧候选需要修订 |
| 原参数映射、源码依据或入口候选 | 创建接入修复草稿，补充指导信息，调用当前分析模型局部修复 | 完整重检后，点击“独立安装新候选” |
| 通用宿主或有限规则尚未覆盖 | 修复平台通用实现，或继续保留缺口 | 不能通过选择资源或点击安装强行放行 |

“创建接入修复草稿”只创建草稿并填写缺口提示，不会立即调用模型。模型修复后也不会自动替换当前接入结果。

“重新检查并接入可用入口”沿用已有完整候选，创建独立修订、完整检查并安装；不请求分析模型，不更改拆分理论。仍缺条件的入口继续保留待接入状态。

接入后通过“查看该来源的能力池”检查具体入口。静态可绑定之后，还需用真实任务核对初始化、调用结果和目标效果。普通对话中可描述所需任务，由模型使用已接入且开放的真实 Unit；不适用的入口不会因这次接入自动变成目标能力。

## 历史会话

对话页顶部提供“历史会话”和“新对话”。历史支持按问题或回答搜索、重新打开、继续对话，以及刷新后恢复当前会话。

每条历史会话提供“删除”，从历史列表移除后可点击“撤销删除”。删除会话不移除任务执行证据；这些记录仍在任务详情中。运行中的会话需等任务结束再删除。

新消息保存在平台本地状态库中。旧版仅保存过任务回答而没有完整问题，因此这些记录标注“仅保存回答”，可查看但需新建会话继续。场景任务与研究运行仍在任务详情中查看。

平台重启不会恢复原来正在执行的任务；该任务标为已中断，已经保存的普通对话仍可查看和继续。

对话框里的“对话或场景任务”只在存在已激活的研究场景任务时显示。它用于运行已保存的场景任务，不是选择 Harness 的入口；普通对话会按需使用已接入且开放的 Unit。

## 服务、模型和权重怎样区分

| 手头的资源 | 在哪里配置 | 怎样选择 |
| --- | --- | --- |
| 已启动的本地或云端 OpenAI 兼容服务 | 服务连接 | OpenAI 兼容接口；再到模型角色应用到对话、分析或教师 |
| 原 Harness 的专用 HTTP API | 服务连接 | 原库专用 HTTP 接口；保留原客户端，不直接充当平台分析模型 |
| 本地模型目录或文件 | 权重资源 | 登记目录或单个文件，填写平台执行环境可见的完整路径 |
| Git 仓库 URL 或本地源码目录 | Harness 接入 | 由分析器查找原功能、入口和依赖 |

“本地／云端”描述部署位置，“API”描述调用方式；接口格式应按服务实际提供的协议选择。仅有权重文件时，登记路径不会自动加载模型或启动推理服务。

登记权重的步骤：准备文件 → 填名称、目录／文件类型及完整路径 → 按原加载器要求声明必要文件 → 保存路径 → 检查资源 → 返回来源的依赖配置选择。禁用的选择框会显示原因：映射未通过、来源正在分析／已摘除，或尚未登记资源。已有权重也不能绕过尚未通过的原参数映射。

原函数从配置字典读取服务地址或模型名时，分析器可用 `parameter_path` 声明原参数内的固定字符串键路径。检查器核对源码读取、单赋值别名及未遮蔽的词法闭包；运行时只解析经过核对的资源引用，其余配置值仍须有用户明确配置作为依据。动态键、字典变更、跨函数配置传递和 CLI 配置文件不会因此自动获得支持。

连接地址须符合原调用方式。有些原客户端会自行追加 `/v1`，此时 Harness 连接保存它所需的根地址；平台直接调用 OpenAI 兼容服务的连接通常包含 `/v1`。平台不会为原库自动增删路径后缀。部分原 SDK 还要求无认证服务使用非空占位符：明确的非密钥 `EMPTY` 可作为用户配置，真实凭据须使用服务的私有凭据引用。

## 仓库保存在哪里

默认启动配置下，Git URL 来源克隆到 `var/prototype/sources/repositories/<来源 ID>/`，分析使用的冻结源码文件保存在 `var/prototype/snapshots/`。如果启动时指定其他 home，则目录位于该状态目录下。

填写本地目录时直接读取原目录，不再复制成 Git 副本。同一来源的普通分析使用已接入的目录；“源码更新”修订会重新冻结本地内容或重新拉取 URL。页面在“来源与分析”和 Harness 配置卡片上显示当前本地源码目录；历史分析仍按各自冻结版本记录。
