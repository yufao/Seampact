# 0.7：规则兑现与实际运行

更新：2026-10-14。本文记录工程机制与真实来源接入事实。当前原型使用正常对话首页、整仓源码工具分析、能力池和两层表格 Q-learning；原生执行继续使用接入仓库的原算法。

## 本版新增的实际机制

| 机制 | 代码已经做什么 | 当前范围 |
|---|---|---|
| B-CALL 原构造绑定 | 用源锚点定位原同步函数和请求，执行完整原直线前缀，取得构造器／工厂返回的真实对象，再绑定原入口 | 顶层同步函数直线前缀、可解析原目标、请求创建发生；未覆盖分支／清理等形式明确缺失 |
| R-INPLACE | 只改原 Call 的 callee 交接，保留原 frame、外围控制、实参求值和结果继续路径；整单元 AST 可逆核对 | 同源普通函数或声明的 `self.method`；同步调用或直接 await 已知 async |
| 结果数据边 | `$result` 连接同一方案前项真实返回值与后项输入，保留本地原生对象引用和冻结类型端口 | 原结果本体或内建 `dict`／`list`／`tuple` 投影；不访问任意对象属性 |
| 成功出口控制边 | 声明顺序、`after` 和数据依赖决定后继使能，异常或 CLI 非零退出停止后继 | 当前顺序方案；业务语义仍标记 `UNRESOLVED` |
| 输入值来源 | 引擎核对任务参数与固定值来源；业务输入需要留在接口中，固定值需原默认值、原调用字面值或用户配置依据 | 明确拒绝模型自选样例值替代业务输入 |

用户已确认有限宿主范围：Python 3.11、本地原生进程、显式生命周期，以及无 frame／调用者身份观察。B-CALL 按原请求的创建发生构造，不将每请求构造擅自改成驻留共享。原 timeout 的起点、时限和作用域保持；其计时区间内的新增排队计入时限，许可后不重置。

这些机制分别记录源码绑定、初始化、实际运行和逐操作未决项。`READY` 是静态绑定状态，`SOURCE_BOUND` 是源码条件依据；二者都不等于完整行为、导出或组合证明。

## 已完成的原生调用

DiSP 修正沿用全部已有分析上下文，新增 2 次实际模型请求；旧候选退出当前能力池。修正后 `insert_token_at_start` 开放真实 `text`、`token` 参数。对话任务 `c9fea72a84724a96aeb13de9c935ea29` 实际提交一个两步方案，第二项通过 `$result` 取得第一项的原返回值：

| 原调用 | 实际输入 | 实际返回 |
|---|---|---|
| `insert_token_at_start` 第一次 | `Observe the red bicycle.`、`[A]` | `[A] Observe the red bicycle.` |
| `insert_token_at_start` 第二次 | 第一项原返回值、`[B]` | `[B] [A] Observe the red bicycle.` |

两次发生均记录 `starts=1`、`receipt=RETURN`、`physical=RETIRED`；原生调用时延约 6.09 ms 和 4.01 ms。实际方案保存一条结果数据边和一条成功出口控制边，执行状态为 `RETURNED`，语义结论仍为 `UNRESOLVED`。对话共 3 次模型请求，整体约 7.69 秒。

上层 Q 更新 1 次，下层 Q 更新 2 次；此次每层决策只有一个候选。它证明本例的原生调用、结果传递和更新链路已经运行，没有提供 RL 收益、完整 DiSP 模型流程、非平凡内部拆分或跨源组合证据。没有启动训练／模型评测脚本。研究比较见[实验方案](研究实验方案.md)。

当前原生调用记录保存在本机私有 `var/prototype/native_composition_2026-10-14.json`；分析历史和原候选保存在本地状态库，均不上传 Git。

## 当前物料与能力缺口

MMCT 和 NeMo 的源码已经补全，但各保留一个未准备的 Git 跟踪资源：

- MMCT：`mmct/image_pipeline/agents/yolov8s.pt`。
- NeMo：`examples/configs/rag/pinecone/kb/data-00000-of-00001.arrow`。

这两个 checkout 保持资源排除后的 sparse 模式；其余跟踪源码文件均在场。LlamaIndex 和 DiSP 已关闭 sparse checkout，所有跟踪文件在场。模型、配置和数据是否能被原加载器使用，还要满足实际入口的资源与依赖条件。

MADL 已额外接入，模型权重尚未准备；相关入口按真实缺口显示 `MISSING`。通用接入可以保留当前有依据的能力，缺少完整模型流程的物料不会被样例或假返回值填补。
