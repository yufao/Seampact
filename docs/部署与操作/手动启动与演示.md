# 启动与使用

适用 0.16.0。流程是提交仓库、自动形成能力、直接发送任务。边界见[当前实现](../设计与实现/当前实现.md)。

## 启动

使用 Python 3.11，远程仓库需要 Git，能力实例自动准备和运行需要可用 Docker 后端。

Windows 在仓库根目录运行 `start.cmd`。其他环境：

```bash
PYTHONPATH=src python -B -m seampact serve --home var/capability-agent --port 8880
```

打开 http://127.0.0.1:8880。可用 `--home` 选择数据目录，`--port` 选择端口。升级前等待在途任务及生成完成，保留原状态；两个平台进程不能同时写同一个目录。

在配置页设置对话模型和分析模型。普通聊天只需对话模型，自动重构使用分析模型；评价教师留待实验需要时配置。凭据使用连接配置，不放入聊天或来源初始化配置。

实例后端需要能构建镜像、启动容器并回连平台。Docker Desktop 可使用 `host.docker.internal` 回连宿主，以实际连通结果为准。平台默认供本机访问。

## 接入和使用

在来源配置提交完整仓库 URL 或本地目录，随后自动生成。模型未配置时来源保留，配置完成后再生成。来源页展示阶段、实际缺口和已生成能力，不需要逐项填写内部接线、分组及启动步骤。

能力池展示可调用能力与资源缺口。明确资源登记后补充绑定，平台自动准备环境。修改正在使用的包或绑定前须等待调用结束和实例释放；不强行替换在途运行。

在首页发送任务。模型在能力接口中选择工具，平台收到完整参数后安排执行，返回结果或文件，模型可以继续流式回答。

“停止交付”停止回答继续显示，同时请求取消在途工作。工具确认停止与模型停算分别记录。文件结果提供下载链接；任务详情保留调用和错误；历史会话及任务按页读取。

## 调度与历史

规则默认管理就绪派发和空闲释放。状态展示配置身份、到达分母、评分是否可用、成本口径及测量缺口。

旧研究运行只读查看和导出；旧训练表单、交替预算偏好和场景快捷执行退出新主线。新工作负载与训练在后续实验设计确定后开始。资源登记见[资源配置](资源配置操作.md)，接入缺口见[仓库生成](分析结果与补齐接入.md)。
