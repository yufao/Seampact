# 办公表格的独立评分

评分在宿主运行，答案和原始评分代码留在业务容器数据挂载之外。只将已交付文件的副本和评分资料以只读方式挂给无网络、只读根文件系统的评分容器。评分容器不挂 Docker socket；评分时间单独记录，不计入业务执行时延。

已有经合成工作簿验证的评分镜像和私有 receipt 时，使用 Git 克隆中的脚本：

```bash
python3 "$SEAMPACT_CODE_DIR/scripts/run_office_spreadsheet_grader.py" "$COLLECTION_DIR" \
  --allowed-root "$AUTHORIZED_ROOT" --grading-root "$PRIVATE_GRADING_SUBSET" \
  --receipt "$GRADER_RECEIPT" --business-container "$SEAMPACT_PLATFORM_NAME"
```

脚本检查任务身份、评分集摘要、receipt 中的不可变镜像 ID、业务容器挂载和三份交付文件的序号与摘要，再写 `native-score.json`；已完成评分中未交付的工作簿记为失败，基础设施失败和准入失败保留未知结果。主实验驱动的 `--grader-command` 可以传 JSON 参数数组，以上命令中的 collection 位置使用字面值 `{collection}`，其余路径由操作者按部署填写。评分集不得放在业务容器的任何挂载目录内。

评分清单不叫 `manifest.json` 时，以 `--grading-manifest` 指定评分根目录内的清单路径。清单摘要必须同时符合任务和 receipt；训练池与评价集清单不同时，各自使用经过核验、绑定相应清单的 receipt。

新建评分镜像时，[Dockerfile.spreadsheet-grader](../../deploy/Dockerfile.spreadsheet-grader) 接受独立的公开评分脚本与上游代码上下文，基础镜像应使用已核实的不可变 ID，系统源应使用固定快照并传入对应的 LibreOffice Calc 精确版本：

```bash
docker buildx build --load --builder default \
  --build-context "grader_code=$SEAMPACT_CODE_DIR/scripts" \
  --build-context "grader_upstream=$VERIFIED_SPREADSHEETBENCH_CHECKOUT" \
  --build-arg "BASE_IMAGE=$PINNED_PYTHON_IMAGE" \
  --build-arg "LIBREOFFICE_CALC_VERSION=$LIBREOFFICE_CALC_VERSION" \
  -f "$SEAMPACT_CODE_DIR/deploy/Dockerfile.spreadsheet-grader" \
  -t "$GRADER_IMAGE_TAG" "$SEAMPACT_CODE_DIR/deploy"
```

上游固定版本及文件摘要必须与评分集清单一致；评分程序运行时会重新核对。镜像记录实际 Python 和 Debian 包清单；即使传入直接依赖版本，若基础镜像、系统源或间接依赖改变，新构建也不应声称与旧镜像等同。验证新镜像的合成工作簿、固定完整镜像 ID 和评分集摘要后才能生成或更新私有 receipt；不要直接复用指向旧镜像的 receipt。
