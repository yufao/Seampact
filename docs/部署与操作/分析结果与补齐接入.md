# 仓库生成与缺口处理

0.16.0 接收完整仓库，产出版本化能力包。普通使用不需要修订台、内部接线或逐个启动运行组。

| 状态 | 含义 |
|---|---|
| RUNNING | 正在冻结、读取、生成、安装或准备 |
| AVAILABLE | 对应生成能力已首调成功，可由 Agent 调用 |
| NEEDS_INPUT | 缺少确定的资源、环境、匹配、样例或释放条件 |
| FAILED | 本次操作失败；事实保留，修复原因后重试 |
| CANCELLED | 已请求结束生成；不证明远端模型停止计费 |

生成器从源码、配置及登记资源确定能自动确定的内容。检查引用、接口、文件身份和生成代码语法，并有限自动修复；这些检查不构成原库语义等价证明。

首调样例须有来源依据，未明确允许的外部写入不能自动执行。尚未通过首调的生成能力不提供给 Agent。必要时补资源或明确调用样例，成功后开放对应能力。

连接凭据与配置分离，权重按登记身份只读挂载。无法确定模型版本、凭据、文件或 Docker 宿主映射时列出具体缺口。已有实例仍在用时不覆盖安装；镜像准备和业务调用成功分别记录。

## 接口

- `POST /api/harnesses`：提交仓库，默认开始生成。
- `POST /api/generations`：对已登记来源生成，输入 `source_id`。
- `GET /api/generations/<id>`：完整事实及缺口。
- `POST /api/generations/cancel`：取消，输入 `id`。
- `POST /api/capabilities/bind`：补资源绑定并自动准备。
- `POST /api/capabilities/invoke`：明确调用能力；普通使用由 Agent 发起。
- `GET /api/artifacts/<sha256>`：获取实际交付文件。

旧分析和实验记录按原格式只读保留。旧修订安装、Unit 方案和预算训练写入口已停用。
