# SeamPact

SeamPact 是面向多种 Agent 应用的能力接入与调度研究平台。0.16.5 沿用仓库接入、能力包独立执行和流式 Agent 主路径，统一模型用途配置，并完善实验执行、原生评分、用量结算和策略版本管理。

[平台设计](docs/设计与实现/Harness接入与调度重设计讨论.md) · [实现与落地计划](docs/设计与实现/实现与落地计划.md) · [当前实现](docs/设计与实现/当前实现.md) · [文档导航](docs/README.md)

平台使用固定版本 Pi Agent core 1.5.2，由它执行模型与工具循环；Python 平台提供模型连接、项目空间、插件和实例调度。实验直接运行同一业务链路，使用数据集原指标判定任务和攻击结果，训练奖励单独配置。AgentDojo 办公原生工具与评分已经接入；完整防护池和三臂调度比较仍在推进，见[办公场景方案](docs/研究实验/办公协作场景方案.md)。

## 启动

平台使用 Python 3.11、Node.js ≥22.19；分析远程仓库需要 Git。首次安装 Pi 固定依赖时，在 `src/seampact/pi_host` 执行 `npm ci --ignore-scripts --no-audit --no-fund`。普通聊天配置对话模型，源码分析配置分析模型，评价教师按实验需要配置。

Linux，在仓库根目录执行：

```bash
PYTHONPATH=src python -B -m seampact serve --home var/capability-agent --port 8880
```

Windows PowerShell，在仓库根目录执行：

```powershell
.\start.cmd
```

启动脚本优先使用已有环境，否则使用当前 Python；新版本默认状态目录为 `var/capability-agent`，旧 `var/prototype` 保留。打开 http://127.0.0.1:8880，Ctrl+C 停止；可用 `--port 8881` 更换端口。

对话和分析模型均支持兼容的 HTTP／HTTPS 接口。地址填写基础路径，平台追加 `/chat/completions`。地址由后端访问，容器内的 localhost 指向该容器自身。凭据使用配置入口，不发到聊天中。

## 使用与实现范围

普通聊天对支持流式的模型增量显示正文，工具参数收齐后通过新能力目录执行。来源生成使用快速清点入口，按需读取 Python 仓库并保留来源追溯；ID、路径、参数和运行环境由本地流程解析，不要求手写 adapter。系统自动准备 Docker 环境；首调未通过的生成能力不提供给 Agent。详细步骤见 [启动与使用](docs/部署与操作/手动启动与演示.md) 和 [仓库生成与缺口](docs/部署与操作/分析结果与补齐接入.md)。

项目资料与会话工作区已经接入更新后的服务。项目资料以只读方式挂入执行容器，会话工作区可写；Docker Python 执行器可在两者边界内运行并受超时限制，已实跑工作簿读写与文件交付。二进制文件可保存和下载；项目文件管理不依赖RAG。实现边界见[工作区与知识资料](docs/设计与实现/上下文记忆与来源更新.md)。

资料检索作为完整能力接入同一 Pi Agent 循环。迁移后的办公链路已实际调用本地 RAG、隔离 Python，并交付 XLSX 与 Markdown；项目和任务占用均正常收尾。同一项目的新会话可在冷启动实例上复用持久索引。该合成链路记录与原生数据集结果分别保存。

默认保留完整能力，只有独立执行和资源管理能带来实际收益时才拆分。规则与 PPO 使用相同的合法就绪及释放候选；质量、交付、时延、RAM／VRAM 由同一冻结目标配置处理。默认使用规则策略，调度器页支持保存和切换策略版本、原样续训、改参创建分支，以及查看绑定版本的任务结果，见[策略版本管理](docs/设计与实现/策略版本管理.md)。训练显式使用已登记的冻结任务与评价方案；普通对话只推理，不隐式训练。通用插件接口不预置某种 QA 或安全场景。

现有运行结果保留在 [实现与运行记录](docs/history/实现与运行记录.md)。五来源审阅、双来源预算及旧人工接线均按原版本解释，不能当作新设计已完成或 RL 全面优于规则的结论。

## 部署与资源

[服务器部署](docs/部署与操作/服务器部署.md) · [Docker](docs/部署与操作/Docker部署.md) · [资源配置](docs/部署与操作/资源配置操作.md) · [运行组与 K8S](docs/部署与操作/运行组与K8S部署.md)

平台、来源运行环境与模型服务各自保存实际身份。受管实例按可执行的生命周期操作管理；已在外部运行的服务只借用连接，不因登记而获得关闭权限。共享资源只计一次，声明预留量与实际占用分开报告。

`src/seampact/` 保存实现，`deploy/` 保存部署工具和模板。新入口不恢复旧 Unit 或启动旧预算训练；旧记录只读保留。源码版本、实际部署与实验结果各有自己的身份，联通事实见当前实现及运行记录。

个人环境实录、模型、数据、凭据、第三方源码和运行状态留在已忽略的本地目录。历史结果入口见 [历史索引](docs/history/README.md)，不要求从旧设计逐篇恢复当前要求。
